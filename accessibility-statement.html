Accessibility Statement

Last Updated: February 5, 2026

Our Commitment to Accessibility

Sterling Executive Group is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) define requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

Our website is designed to conform to WCAG 2.1 Level AA standards. This means we meet the internationally recognized standards for web accessibility and comply with:

  • WCAG 2.1 Level AA - Web Content Accessibility Guidelines
  • European Accessibility Act (EAA) - EU accessibility requirements
  • EN 301 549 - European standard for digital accessibility
  • Section 508 - U.S. federal accessibility standards

Measures to Support Accessibility

We have taken the following measures to ensure accessibility:

Organizational Commitment

  • Include accessibility as part of our mission statement
  • Provide continual accessibility training for our staff
  • Assign clear accessibility goals and responsibilities
  • Employ formal accessibility quality assurance methods

Technical Implementation

  • ✓ Semantic HTML5 structure with proper heading hierarchy
  • ✓ ARIA landmarks for screen reader navigation
  • ✓ Skip navigation link to bypass repetitive content
  • ✓ Keyboard-accessible navigation and interactive elements
  • ✓ Visible focus indicators for keyboard users
  • ✓ Color contrast ratio of 4.5:1 or higher for text
  • ✓ Responsive design that works on all device sizes
  • ✓ Text can be resized up to 200% without loss of content
  • ✓ Reduced motion support for users with vestibular disorders
  • ✓ Alternative text for images and meaningful content
  • ✓ Form labels and error messages properly associated
  • ✓ Logical tab order throughout the website

Accessibility Features

Keyboard Navigation

Our website can be navigated entirely using a keyboard:

  • Tab: Move forward through links and form controls
  • Shift + Tab: Move backward through links and form controls
  • Enter: Activate links and buttons
  • Space: Scroll down the page or activate buttons
  • Arrow Keys: Navigate within dropdown menus
  • Escape: Close modals and dropdown menus

Screen Reader Support

Our website is compatible with popular screen readers including:

  • JAWS (Windows)
  • NVDA (Windows)
  • VoiceOver (macOS, iOS)
  • TalkBack (Android)
  • Narrator (Windows)

Visual Accessibility

  • High contrast color schemes
  • Resizable text without loss of functionality
  • No content relies solely on color to convey information
  • Text and interactive elements are clearly distinguishable

Cognitive Accessibility

  • Clear and consistent navigation structure
  • Descriptive page titles and headings
  • Simple language where possible
  • Predictable and consistent layout

Assessment and Testing

We regularly test our website for accessibility using:

Automated Testing Tools

  • WAVE Web Accessibility Evaluation Tool
  • axe DevTools browser extension
  • Google Lighthouse accessibility audits
  • Accessibility Checker

Manual Testing

  • Keyboard-only navigation testing
  • Screen reader testing with multiple tools
  • Color contrast analysis
  • Mobile device accessibility testing
  • User testing with people with disabilities

Known Limitations

Despite our best efforts to ensure accessibility, there may be some limitations. Below are known issues we are working to resolve:

  • ⚠ Some older PDF documents may not be fully accessible (we are working to update these)
  • ⚠ Third-party embedded content (e.g., social media feeds) may not meet our accessibility standards
  • ⚠ Some legacy multimedia content may lack captions or transcripts (being updated)

We are actively working to address these limitations and will provide updates as improvements are made.

Assistive Technologies

Our website is designed to be compatible with the following assistive technologies:

  • Screen readers
  • Screen magnification software
  • Speech recognition software
  • Alternative input devices
  • Browser text-to-speech tools

Browser and Device Compatibility

Our website is designed to work with the following browsers and assistive technologies:

  • Recent versions of Chrome, Firefox, Safari, and Edge
  • iOS devices with VoiceOver
  • Android devices with TalkBack
  • Windows devices with JAWS, NVDA, or Narrator
  • macOS devices with VoiceOver

Third-Party Content

We strive to ensure that third-party content integrated into our website (such as social media embeds, videos, or external widgets) meets accessibility standards. However, we cannot guarantee the accessibility of content from external sources.

If you encounter accessibility barriers with third-party content, please let us know so we can work with the provider to resolve the issue or provide an alternative.
